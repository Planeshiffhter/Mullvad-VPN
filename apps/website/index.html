Start carefully

Install the private extension

The extension is a browser proxy. It does not create a system-wide VPN, protect other apps, or prove a country from a location label.

  1. Build in the cloud workspace. Run npm ci and npm run build. The unpacked extension is written to dist/extension.
  2. Install in your Chrome. Transfer the build to your computer, open chrome://extensions, turn on Developer mode, and choose Load unpacked.
  3. Configure a trusted service. Open the extension and supply the HTTPS control API origin and your founder credentials. The certificate must be trusted by Chrome. Do not bypass certificate errors.
  4. Verify the route. Connect only to an authorized gateway. Local fixture verification is a development check; a live US exit also needs provider-region evidence and real exit-IP validation.
  5. Complete acceptance checks. Check disconnect, expired and revoked grants, outages, browser restarts, DNS, WebRTC, and IPv6 on your actual device before private use.

Data and scope

This view requests account usage and grant metadata from your own control API. It loads no third-party scripts, fonts, or analytics. It does not display browsing history or proxy passwords. Operational data retention and hosting practices need review before release; no independent audit or no-logs guarantee is claimed.
