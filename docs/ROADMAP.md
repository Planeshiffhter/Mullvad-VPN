# Phased roadmap — build proof, then expand

The project has **two tracks**: a hard **$0 additional spending private prototype** and a future **commercial product**. Do not treat future features as approved expenses.

## Phase 0 — Documentation and research

- Contributor-ready repository and original plan committed.
- Evidence-based shortlist and license/security audit.
- Architecture threat model and reproducible test strategy.
- **Exit:** owners and developers can identify current status, the first task, risks and blocked prerequisites.

## Phase 1 — Private Chrome + US browser proxy

- Tasks 1–20 in [../TASKS.md](../TASKS.md) are authoritative.
- One real US endpoint only when an authorized **zero-incremental-cost** host passes preflight.
- MVP must demonstrate authentication, transport confidentiality as claimed, route verification, revocation, quota and failure tests.
- **Exit:** a reproducible private extension, live US proof, manual browser verification, actual $0 observed cost and operational handover; otherwise remain blocked.

## Phase 2 — Robust browser product and 1–2 more countries

- Location abstraction and regional deployment automation; enable only verified real hosts.
- Refine UI, auth, browser behavior, ad/tracker controls if justified.
- Broader cross-browser and safety testing.
- **Gate:** real hosting permissions/costs and support obligations approved; security gaps addressed.

## Phase 3 — Native full-device VPN

- WireGuard or another reviewed protocol in signed clients for Windows, macOS, Linux, Android, iOS as justified.
- OS-specific kill-switch, DNS, reconnection and split-tunneling functionality tested per-platform.
- **Gate:** protocol/platform architecture review, device testing and signing/distribution resources.

## Phase 4 — Commercial product

- Public signup, entitlement management, subscriptions, customer support, legal and privacy operations.
- Capacity planning, abuse handling, data retention, independent security review, incident response and realistic cost model.
- **Gate:** owner approval for operating expenses, applicable jurisdiction/compliance and release readiness.

## Phase 5 — Global competitor

- More regions, scalable operations, multi-hop and advanced privacy (only where technically justified).
- Independent performance benchmarks and transparent uptime/privacy practices.
- **Gate:** evidence-backed reliability, sufficient funding, active operations and user trust.

There are **no promised dates**; proceed when acceptance criteria are met, not by calendar.
