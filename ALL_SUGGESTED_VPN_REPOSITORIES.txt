PURPOSE
-------
Complete inventory of the GitHub repositories suggested during VPN project planning,
including original two selections, earlier extension examples, networking,
identity, privacy, infrastructure, UI, testing, and security libraries.

IMPORTANT
---------
- This is a CANDIDATE/REFERENCE INVENTORY, not a list of code imported to this repo.
- Selected core networking projects: apify/proxy-chain (current), WireGuard/wireguard-go (future).
- Existing implementation already uses proxy-chain, ipaddr.js and Playwright; check current branch and lockfile.
- Gitleaks has been introduced on the implementation branch; inspect latest CI before claiming it is released.
- Do not blindly merge 23 repositories. Compare exact licenses, security, maintenance,
  transitive dependencies, and product relevance before integrating each.
- The Chrome browser proxy does NOT provide device-wide VPN tunneling.
- Keep project source, original design and business rules in our owned repository.
- Do not buy infrastructure or deploy public servers without owner approval.
