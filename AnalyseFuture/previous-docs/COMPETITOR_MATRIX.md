# Competitor benchmark — aspiration, not current feature parity

Benchmark products: **NordVPN, Proton VPN, ExpressVPN**. The identity of "market #1" depends on review criteria; this is a qualitative product benchmark, **not an assertion that we are competitive today**. Verify current competitor capabilities using official product docs before relying on any row.

| Dimension | What strong competitors are known for | Our target | Our current status |
| --- | --- | --- | --- |
| One-click connection | Clear simple UX | Accurate connect/disconnect | Not built |
| Network footprint | Many locations and capacity | US first; gradual expansion | No host verified |
| Real VPN protection | Native tunneling | OS clients later | Not built |

| Privacy tools | Ad/tracker/malware filtering | Consider after secure MVP | Deferred |

| Independent security | Audits and disclosure processes | Auditable implementation | No audit |
| Customer plans | Billing, customer support | Later commercial phase | Deferred |
| Design polish | Consistent cross-device interfaces | Original premium UX | Not built |

## How to turn comparisons into work

For any proposed feature, record: user need → actual supported platforms → upstream library option → risk and privacy impact → tests → cost → explicit milestone. Do not add features purely to inflate a checklist.

## Differentiation hypothesis

Focus on truthfulness, user trust, understandable controls, lean performance and operational transparency. First product success is **one secure, reliably verified US connection**, not a marketing badge or feature count.
