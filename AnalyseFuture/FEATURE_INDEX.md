## What the checks mean

**Every payload** is checked by `python3 -B tools/verify_feature_archive.py --verify-git` from the repository root: exact source Git tree/blob membership, hashes/bytes/modes, distinct paths, active references, complete archive membership and all 99 earlier preservation identities. This checks documents, tests, code copies, binary Word data and provenance without running archived code. `--verify-filesystem-modes` additionally checks the original migration instance's full permission bits; default verification checks Git file type/executable identity and remains portable across checkout umasks. Empty/parent folder provenance is in the relocation map; each old folder maps to its new feature parents.

**Active-feature integration** rows additionally map to current tests for the maintained counterpart. **Preservation-only** rows are research, guidance, recorded history or inert automation; no application behavior is invented for them. Related test links in the JSON are navigation, not evidence that proposed algorithms exist. A country-selector proposal and the Word document do not implement VPN routing.

Archived embedded links/commands remain their exact historical text. Resolve old paths through the map rather than rewriting payload bytes or executing archived agent/workflow directions. Managed browser skips, native build/device gaps and fixtures retain their honest boundaries.
